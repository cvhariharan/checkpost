# Queries

The Query page runs osquery SQL against selected machines, machine groups, or platforms. Check the target count before running expensive queries across a large fleet.

## Saved queries

Save a query to reuse its SQL and target selection. Private queries are visible only to their owner. Public queries are visible to everyone, but only their owner can update or delete them.

## Query results

Query runs keep the status and results for each targeted host. Select a host to browse or download its rows, or download the complete run as CSV.
